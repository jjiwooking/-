# 월마감 손익 변동 원인분석 시스템

ERP/Excel에서 추출한 월별 상세 데이터를 이용해 **영업이익이 왜 변했는지를 금액으로 분해하고 원본 데이터까지 추적하는 재무데이터 분석 프로젝트**입니다.

> **프로젝트 성격:** 포트폴리오 및 프로토타입  
> **데이터:** 실제 기업 데이터가 아닌 전부 합성(Synthetic) 데이터  
> **중요:** 현재 버전은 운영 ERP를 대체하는 상용 재무시스템이 아닙니다.

## 해결하려는 문제

일반적인 손익 대시보드는 `매출액`, `매출원가`, `영업이익`이 얼마나 변했는지는 보여줄 수 있습니다. 이 프로젝트는 그 다음 단계인 **“왜 변했는가?”**에 초점을 둡니다.

예시 흐름:

```text
영업이익 감소
   ↓
매출 / 매출원가 / 판매비와관리비 영향 분해
   ↓
제품 / 고객 / 원가구분 / 계정과목별 Drill-down
   ↓
관련 원본 데이터 확인
   ↓
계산된 사실을 기반으로 경영보고 초안 생성
```

## 핵심 기능

- 월별 손익 비교: 매출액 / 매출원가 / 매출총이익 / 판매비와관리비 / 영업이익
- 영업이익 변동 브리지 분석
- 매출 변동을 판매량효과 / 판매단가효과 / 신규·판매중단 효과로 분해
- 제조원가 변동을 원가구분 → 제품 수준으로 추적
- 판관비 변동을 계정과목 → 부서 → 거래처 수준으로 추적
- 예산 대비 실적 비교
- 계산된 사실을 기반으로 경영보고 초안 생성
- 회사별 Excel 시트/열 이름을 화면에서 매핑
- 원본 금액·수량·계정과목·제품·고객 등을 대시보드에서 직접 수정
- 제목·메뉴명·분석도구명·열 표시명·금액단위 등을 코딩 없이 수정

## 기술 구성

```text
Excel
  ↓
Pandas
  ↓
재무 분석 엔진
  ↓
Streamlit
  ↓
Plotly / 분석표 / 경영보고
```

- Python
- Pandas
- Streamlit
- Plotly
- OpenPyXL / XlsxWriter

## 실행 방법

### Windows

`START_HERE.bat`를 실행합니다.

### 직접 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```

### 분석 엔진 테스트

```bash
python tests/test_engine.py
```

### GitHub에 게시

GitHub에서 빈 저장소를 만든 뒤 Windows에서 `PUBLISH_TO_GITHUB.bat`를 실행하면 권장 커밋 순서대로 저장소를 구성하고 push하도록 만들었습니다. 자세한 순서는 [`docs/04_GitHub_업로드_순서.md`](docs/04_GitHub_업로드_순서.md)를 참고하세요.


현재 기준 샘플 데이터에 대해 **20개 핵심 계산 검증을 통과**합니다.

## 샘플 데이터

### 1. 검산용 Demo

`sample_data/demo/한빛정밀_월마감_손익분석_샘플.xlsx`

결과를 의도적으로 설계하여 계산 로직이 정확한지 검증하는 데이터입니다.

### 2. 결과 미지정 Random Test

`sample_data/random/`에는 결과를 먼저 정하지 않고 원본 값을 난수로 생성한 샘플 5개가 있습니다.

목적은 특정 정답 데이터에만 맞춘 분석이 아니라 **처음 보는 입력에도 동일한 분석 로직이 적용되는지 확인**하는 것입니다.

## 검증용 Demo의 주요 결과

| 항목 | 2026년 6월 | 2026년 7월 | 변동 |
|---|---:|---:|---:|
| 매출액 | 5,000,000,000원 | 4,850,000,000원 | -150,000,000원 |
| 매출원가 | 3,200,000,000원 | 3,330,000,000원 | +130,000,000원 |
| 판매비와관리비 | 1,280,000,000원 | 1,120,000,000원 | -160,000,000원 |
| 영업이익 | 520,000,000원 | 400,000,000원 | **-120,000,000원** |

영업이익 변동 브리지:

```text
매출액 영향             -150,000,000원
매출원가 영향           -130,000,000원
판매비와관리비 영향      +160,000,000원
-----------------------------------
영업이익 변동            -120,000,000원
```
