# 데이터 구조

프로그램 입력은 하나의 Excel 파일 안에 다음 4개 시트를 사용하는 구조입니다.

## 매출상세
주요 열:
- 회계연도
- 회계월
- 매출일자
- 고객코드 / 고객명
- 제품코드 / 제품명
- 수량
- 판매단가
- 매출액

## 제조원가상세
주요 열:
- 회계연도
- 회계월
- 제품코드 / 제품명
- 원가구분
- 금액

원가구분 예:
- 원재료비
- 외주가공비
- 직접노무비
- 수도광열비
- 감가상각비

## 판관비상세
주요 열:
- 회계연도
- 회계월
- 부서코드 / 부서명
- 계정코드 / 계정과목
- 거래처코드 / 거래처명
- 금액

## 예산
주요 열:
- 회계연도
- 회계월
- 손익항목
- 예산금액

## 회사마다 열 이름이 다른 경우
대시보드의 열 매핑 기능에서 프로그램 표준 열과 회사 Excel 열을 연결하도록 설계했습니다.
