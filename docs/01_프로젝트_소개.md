# 프로젝트 소개

## 프로젝트명
**월마감 손익 변동 원인분석 시스템**

## 목적
월마감 후 손익이 전월·예산 대비 왜 변했는지를 단순 조회가 아니라 원인 금액으로 분해하고, 세부 데이터까지 추적하는 재무데이터 분석 프로토타입입니다.

## 주요 사용자 가정
- 재무팀
- 관리회계 담당자
- FP&A
- 경영관리 담당자

## 핵심 질문
1. 이번 달 영업이익은 얼마나 변했는가?
2. 매출, 매출원가, 판매비와관리비 중 무엇이 영향을 줬는가?
3. 어떤 제품·고객·원가·계정과목이 주요 원인인가?
4. 계산 근거가 되는 원본 행은 무엇인가?
5. 경영진에게 어떤 사실을 보고해야 하는가?

## 설계 원칙
- 숫자 계산은 AI가 아니라 코드가 수행합니다.
- 확인되지 않은 실제 업무 원인을 단정하지 않습니다.
- 원본 데이터와 계산 결과를 분리합니다.
- 표시용 금액 형식과 계산용 숫자값을 분리합니다.
